# 공공데이터 건강검진표 — 한국체육산업개발 개방 데이터 점검

한국체육산업개발(주)가 공공데이터포털에 개방한 데이터 58종(파일 30 · 오픈 API 28)을 같은 규칙으로 점검하고,
데이터마다 **판정 · 발견 사항 · 고치는 방법**을 한 페이지로 보여 줍니다. 2026년도 한국체육산업개발 공공데이터 활용 경진대회 출품작.

- 점검 결과 페이지: https://tkddn647-ship-it.github.io/kspo-opendata-check/ (`site/`)
- 점검일: 2026-11-23 (공공데이터포털에서 수집)

## 결과 요약 (2026-11-23)

| 판정 | 수 |
|--|--|
| 점검 필요 | 2 |
| 주의 | 14 |
| 양호 | 42 |

기관 전체: '공공데이터 개방목록' 파일(42종)에 포털에 있는 17종이 빠져 있음, 개방목록에만 있고 포털에 없는 2종,
개방목록 관리부서가 옛 부서명, 58종 중 44종의 수정일이 하루(2026-09-21)에 몰림.
숫자는 `python check.py` 를 돌리면 `out/findings.json` 에서 그대로 다시 나옵니다.

## 점검 규칙 (`check.py`)

판정은 전부 규칙으로 합니다. AI는 판정에 쓰지 않습니다.

| 규칙 | 판정 | 내용 |
|--|--|--|
| 갱신예정일 | 점검 필요 | 포털의 '차기 등록 예정일'이 점검일보다 앞인데 새 파일이 없음 |
| 설명복사 | 점검 필요 | 설명이 다른 데이터 설명과 거의 같고, 이 데이터 제목의 낱말이 설명에 없음 |
| 최신성 | 주의 | 파일 안 마지막 날짜가 갱신 주기의 두 배보다 오래됨 (월간 60일, 반기 365일, 연간 730일) |
| 설명기간 | 주의 | 설명이 말하는 자료 마지막 해(예: '2013년 부터 2024년 강좌까지')보다 실제 자료가 더 최근까지 있음 |
| 중복 | 주의 | 모든 칸이 같은 행. 행 번호 열이 없으면 "실제 중복인지 판단 불가"로 표시 (담당자 확인) |
| 설명내용 | 주의 | 설명이 말하는 항목이 파일에 없음 (예: '동2문/남2문/북2문 주차구역'이라는데 구역 열이 없음) |
| 열이름중복 · 행수 | 주의 | 포털 항목 정보에 같은 열이 두 번, 포털 '전체 행'과 실제 행 수가 다름 |
| 입출차 | 점검 필요/참고 | 출차가 입차보다 앞서면 점검 필요, 체류 0분·10분 미만·24시간 넘음·출차 빈칸 건수는 참고 |
| 자리표시날짜 · 빈열 · 먼미래날짜 | 참고 | 1990-01-01·9999-12-31, 절반 넘게 빈 열, 3년 넘게 뒤 날짜 |
| 오탈자 | 참고 | `ai_review.json`: AI가 찾은 후보 중 포털 원문과 글자 그대로 대조해 확인한 것만 |

'자료 기준일'은 파일 안 가장 최근 날짜입니다 (자리표시 날짜, 점검일보다 30일 넘게 뒤 날짜 제외).
오픈 API는 인증키가 있어야 응답을 받을 수 있어 이번에는 설명·메타데이터만 봤습니다.

## 다시 돌리기

```bash
# 1) 브라우저로 data.go.kr 을 열고 개발자 도구 콘솔에 tools/collect_in_browser.js 를 붙여 넣어 실행
#    → kspo_opendata.json.gz 내려받아짐 (포털 내려받기 제한이 뜨면 스크립트가 멈춤)
python tools/unpack.py ~/Downloads/kspo_opendata.json.gz   # raw/ 에 풀기
python check.py                                            # out/findings.json, out/summary.csv, site/data.js
python -m unittest discover -s tests                       # 규칙 테스트 16개
```

외부 라이브러리 없이 Python 3.10+ 표준 라이브러리만 씁니다.

## 폴더

```
check.py                 점검 규칙
ai_review.json           설명문 오탈자 후보 (원문 대조 확인된 것만)
raw/                     2026-11-23 수집 원본 (CSV는 UTF-8로 변환, 21만 행 입출차는 .csv.gz), _meta/_catalog/_desc.json
out/                     점검 결과 (findings.json, summary.csv)
site/                    결과 페이지 (index.html + data.js)
tools/                   수집 스크립트, 안내문 HWP 텍스트 추출
tests/                   규칙 단위 테스트
```

## 한계

- 이미지 파일 1종(생태갤러리 JPG)은 내용 점검을 하지 않았습니다.
- '중복'은 행 번호 열이 없는 데이터에서는 같은 날 같은 주문이 여러 건일 수도 있어 확정이 아니라 확인 요청입니다.
- '설명기간'은 설명문의 연도 표현을 규칙으로 읽습니다. 규칙이 못 읽는 표현은 놓칠 수 있습니다.
