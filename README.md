# 강좌 공백 지도 — 한국체육산업개발 스포츠센터 4곳의 강좌 편성 진단

2026년도 한국체육산업개발 공공데이터 활용 경진대회 출품작. 화면 네 개가 같은 데이터·같은 코드에서 나옵니다.

0. **강좌 공백 지도** (`site/gap.html`, `gap.py`) — 기관 편성 담당자용, 이 사례의 중심. 운영 중 강좌의 대상 연령을 강좌명의 출생연도·나이와
   수강대상 칸으로 정하고, 연령대(유아·초등·중고생·청년·중년·어르신) × 시간대(평일 새벽·아침, 낮, 오후, 저녁, 주말)로 정원을 나눠
   센터가 있는 시·구의 연령별 주민등록 인구(행정안전부, `tools/fetch_population.py`로 받음)와 비교합니다. 주민 1,000명당 정원이 가장 적은 칸을
   '검토할 칸'으로 보여 주고 CSV로 내려받을 수 있습니다. 수요 측정이 아니라 비교이며, 기준과 한계를 화면에 적었습니다.
1. **강좌 찾기** (`site/index.html`, `courses.py`) — 시민용. 올림픽수영장·올림픽스포츠센터·일산·분당 강좌정보 파일 4종을
   한 형식으로 맞춰, 로그인 없이 요일·시작 시각·대상(퇴근 후·주말·어린이·청소년·실버)으로 찾습니다.
   강좌마다 자료에서 마지막으로 바뀐 달을 붙이고, 1년 넘게 바뀐 기록이 없는 강좌는 '운영 여부 센터 확인'으로 표시합니다.
2. **데이터 분석** (`site/analysis.html`, `analysis/`) — 원본을 SQLite에 넣고 질문마다 SQL 한 개(`analysis/queries.sql`, 창 함수·재귀 CTE)로 답을 내고,
   순열 검정·부트스트랩 신뢰구간으로 확인. `python analysis/run.py` 로 같은 숫자가 다시 나옴 (표준 라이브러리만, 난수 씨앗 고정).
3. **데이터 건강검진** (`site/check.html`, `check.py`) — 기관용. 개방 데이터 58종(파일 30 · 오픈 API 28)을 같은 규칙으로 점검해
   데이터마다 **판정 · 발견 사항 · 고치는 방법**을 보여 줍니다. 강좌 찾기를 만들며 걸린 문제(날짜 열에 기간이 든 것, 종료 처리 안 된 강좌,
   요일 칸에 강습일·자유이용일이 섞인 것, 신청에 필요한 항목 미개방)도 규칙으로 넣었습니다.

- 페이지: https://tkddn647-ship-it.github.io/kspo-opendata-check/ (`site/`, 휴대폰에서 '홈 화면에 추가' 가능)

### 바로 쓰는 기능
- 강좌 이름 검색, 퇴근 후·주말·아이와·청소년·실버 버튼, 센터·종목·요일·시각·대상 거르기
- 강좌마다 '센터 안내', '온라인 수강신청' 링크와 **내 캘린더에 넣기**(.ics, 매주 반복 4주)
- **지금 올림픽공원 주차**: 한국체육산업개발이 공개한 실시간 주차 API(`parkingorsApi.do`, 기관 누리집에 공개된 키)를 화면에서 직접 부름
- 주차 기록: `.github/workflows/parking-log.yml` 이 예약 실행으로 같은 API를 자동으로 불러 `parking-log` 브랜치에 쌓고, 화면은 같은 요일 종류·시각 기록이 5회 넘게 모이면 '평소보다 많음/비슷/적음'을 보여 줌
- **2025 주차·공연**: 문화공공데이터광장 API(올림픽공원 2025 입출차정보 241만 건, 2025 공연 연계 데이터)를 `tools/fetch_inout2025.py`·`tools/fetch_linked2025.py`로 받아(키는 Secrets `KCISA_KEY_008`·`KCISA_KEY`) 평일·휴일·대형 공연 날의 시각별 주차 대수와 예측 오차를 계산. 실시간 주차를 2025년 같은 시각 평균과 비교(9~18시만)
- 자료 자동 갱신: `.github/workflows/refresh.yml` 이 매주 월요일 06:17(한국 시각) 포털의 강좌 파일 5종 수정일을 보고, 바뀌었으면 받아서 다시 만들고 배포 (`tools/refresh_courses.py`, 포털 내려받기 제한이 뜨면 멈추고 기존 자료 유지)
- **시간표로 고르기**: 요일 × 시작 시각 표의 칸(강좌 수)을 눌러 그 시간 강좌만 보기
- 정리된 강좌 자료 재공개: `site/courses.csv` (센터 4곳을 한 형식으로, 누구나 다시 사용)
- 조건을 주소에 담아 링크로 공유, 글자 크게, 오프라인에서도 마지막 목록 열림(서비스 워커)
- 점검일: 2026-11-23 (공공데이터포털에서 수집)

## 점검 규칙 (`check.py`)

판정은 전부 규칙으로 합니다. AI는 판정에 쓰지 않습니다.

| 규칙 | 판정 | 내용 |
|--|--|--|
| 갱신예정일 | 점검 필요 | 포털의 '차기 등록 예정일'이 점검일보다 앞인데 새 파일이 없음 |
| 설명복사 | 점검 필요 | 설명이 다른 데이터 설명과 거의 같고, 이 데이터 제목의 낱말이 설명에 없음 |
| 최신성 | 주의 | 파일 안 마지막 날짜가 갱신 주기의 두 배보다 오래됨 (월간 60일, 반기 365일, 연간 730일) |
| 설명기간 | 주의 | 설명이 말하는 자료 마지막 해(예: '2013년 부터 2024년 강좌까지')보다 실제 자료가 더 최근까지 있음 |
| 중복 | 주의 | 모든 칸이 같은 행. 행 번호 열이 없으면 "실제 중복인지 판단 불가"로 표시 (담당자 확인) |
| 설명내용 | 주의 | 설명이 말하는 항목이 파일에 없음 (예: '동2문/남2문/북2문 주차구역'이라는데 구역 열이 없음) |
| 열이름중복 · 행수 | 주의 | 포털 항목 정보에 같은 열이 두 번, 포털 '전체 행'과 실제 행 수가 다름 |
| 입출차 | 점검 필요/참고 | 출차가 입차보다 앞서면 점검 필요, 체류 0분·10분 미만·24시간 넘음·출차 빈칸 건수는 참고 |
| 시각형식 | 점검 필요 | 시각 열의 분·초 자리에 날짜의 월·일이 들어 있음 (예: 2026-08-12 → 17:08:12) |
| 열값형식 | 주의 | 날짜 열에 기간(시작~종료)이 들어 있고 옆 종료 열엔 시작일이 들어 있음 |
| 운영중강좌 | 주의 | 종료일 9999(운영 중)인데 파일의 마지막 달보다 1년 넘게 바뀐 기록이 없거나 시작일이 1990-01-01 |
| 요일 | 참고 | 강좌명의 요일(예: 화목)과 요일 열(예: 월~일)이 다름 — 강습일과 자유이용일이 한 칸에 섞임 |
| 시민 서비스 | 주의 (기관 전체) | 강좌정보 파일에 남은 자리·신청 기간·선착순/추첨·대상별 요금 열이 없음 |
| 자리표시날짜 · 빈열 · 먼미래날짜 | 참고 | 1990-01-01·9999-12-31, 절반 넘게 빈 열, 3년 넘게 뒤 날짜 |
| 오탈자 | 참고 | `ai_review.json`: AI가 찾은 후보 중 포털 원문과 글자 그대로 대조해 확인한 것만 |

'자료 기준일'은 파일 안 가장 최근 날짜입니다 (자리표시 날짜, 점검일보다 30일 넘게 뒤 날짜 제외).
오픈 API는 인증키가 있어야 응답을 받을 수 있어 이번에는 설명·메타데이터만 봤습니다.

## 다시 돌리기

```bash
# 1) 브라우저로 data.go.kr 을 열고 개발자 도구 콘솔에 tools/collect_in_browser.js 를 붙여 넣어 실행
#    → kspo_opendata.json.gz 내려받아짐 (포털 내려받기 제한이 뜨면 스크립트가 멈춤)
python tools/unpack.py ~/Downloads/kspo_opendata.json.gz   # raw/ 에 풀기
python check.py                                            # out/findings.json, out/summary.csv, site/data.js
python courses.py                                          # site/courses.js, out/courses_summary.json
python parking2025.py                                      # out/parking2025.json (2025 입출차 241만 건 + 공연, 예측 검증)
python analysis/run.py                                     # out/kspo.db, site/analysis.js, out/analysis.md
python -m unittest discover -s tests                       # 테스트 30개
```

외부 라이브러리 없이 Python 3.10+ 표준 라이브러리만 씁니다.
